# getPhone

```ts
getPhone: () => Promise<GetPhoneResponse>
```

Возвращает не строку с номером, а подписанный конверт. **По нему можно авторизовать пользователя:** подпись подтверждает, что номер выдали мы, именно вашей мини-апке и именно этому пользователю. Требует права `phone:read` - [что вы присылаете и что получаете](/onboarding).

```json
{
  "app_id": "34d5810c-7c36-11eb-82e7-f2189812cd57",
  "auth_date": 1756715400,
  "nonce": "7c9e6679-7425-40de-944b-e07fc1f90ae7",
  "user": "{\"id\":\"3f1a9c40-77ad-4e0f-9c3d-11c2a0f5e881\"}",
  "phone": "7011234567",
  "sign": "2faf04cc47bef45ce6607a20d3703b101730b6ceb602295e3b8c818e2bc4bd83"
}
```

Подпись в примере посчитана на секрете `my_secret_key` - на нём же посчитан [тестовый вектор](/verify), так что на этом конверте можно проверить свою реализацию.

| Поле | Что означает |
|---|---|
| `app_id` | Ваша мини-апка |
| `auth_date` | Unix-время выпуска, сек |
| `nonce` | Своё на каждый вызов |
| `user` | Тот же псевдоним, что в контексте запуска. Сверьте - конверт должен относиться к текущему пользователю |
| `phone` | Номер в том виде, в каком он хранится у нас: ровно 10 цифр без кода страны, например `7011234567` |
| `sign` | Подпись остальных полей |

## Исходы вызова

| Исход | Код ошибки | Что делать |
|---|---|---|
| Конверт получен | - | Передать бэкенду целиком |
| У абонента нет подтверждённого номера | `PHONE_UNAVAILABLE` | Показать свою форму ввода номера |
| Право `phone:read` не выдано или пользователь гость | `PERMISSION_DENIED` | Не показывать кнопку: проверяйте `scope` и `auth` |
| Приложение не дождалось ответа | `TIMEOUT` | Предложить повторить |
| Ошибка на нашей стороне | `INTERNAL` | Предложить повторить позже |

## Проверка на бэкенде

Та же, что у [контекста запуска](/verify), с полем подписи `sign`:

1. Проверить `sign`. Не сошлась - отказать.
2. Проверить `auth_date` - окно 300 секунд в обе стороны.
3. Сверить `user` с тем, что пришёл в контексте запуска.

Реестр `nonce` для конверта - та же рекомендация, что для [контекста запуска](/launch-context).

::: danger Номер с клиента доказательством не является
Номер, разобранный на клиенте и отправленный бэкенду отдельным полем, ничего не подтверждает: страница может прислать вашему бэкенду любое значение. Передавайте конверт целиком, таким, каким его выдало приложение, и проверяйте подпись на сервере.
:::
