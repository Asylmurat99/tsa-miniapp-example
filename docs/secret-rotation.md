# Смена секрета

Мы можем выдать вам второй секрет, не отзывая первый - так ключ меняется без простоя.

- Пока действуют оба секрета, контекст запуска и конверт `getPhone` мы подписываем **прежним**, тем, что вы получили раньше.
- Когда мы сообщим об отзыве прежнего, подписывать начинаем новым.

**Проверяйте контекст обоими ключами**, пока не получите уведомление об отзыве прежнего: подпись сошлась по любому из двух - контекст подлинный.

::: warning
Если переключить проверку на новый секрет сразу после его получения, запуски перестанут проходить: мы в этот момент ещё подписываем прежним.
:::
