# Частые ошибки

Подпись не сходится или сессия не поднимается - почти всегда одна из этих причин.

- Разобрали `location.hash` как query-string и ищут поля контекста прямо в нём. Поля лежат внутри `tsaWebAppData`, его нужно сначала взять и декодировать.
- Декодировали значение `tsaWebAppData` дважды. Декодирование одно; `user` внутри остаётся закодированным до разбора query-string.
- Пересобрали JSON в `user` перед проверкой подписи.
- Собрали каноническую строку из `initDataUnsafe` вместо исходной строки контекста.
- Отправили на бэкенд `initDataUnsafe` или пересобранный объект вместо строки. Подпись посчитана по исходным байтам: после пересборки теряются порядок и кодирование полей.
- В `/api/phone` передали только номер, а не конверт целиком. Номер без подписи ничего не подтверждает.
- Забыли исключить поле с подписью из канонической строки.
- Проверили конверт `getPhone()` по `hash`, а контекст запуска по `sign`. У каждого своё поле, не перепутайте.
- Не отсортировали ключи либо взяли значения до декодирования.
- `auth_date` в конверте - число, а в канонической строке это его десятичная запись без изменений. Не переформатируйте и не приводите к дате.
- Завели реестр `nonce`, но хранят значения меньше 900 секунд: повтор в конце окна пройдёт.
- Переключили проверку на новый секрет, не дождавшись уведомления об отзыве прежнего - [смена секрета](/secret-rotation).
- Зарегистрировали адрес без `/app/`, и приложение открыло сайт документации вместо мини-апки.
